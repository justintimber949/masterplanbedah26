## 🗓️ TIMELINE STASE BEDAH

> [!note] Urutan Sub-Stase
> Ini urutan yang kamu jalani — penting untuk konteks belajar!

```
┌─────────────────────────────────────────────────────┐
│  1. IGD 1         → Fondasi emergency semua stase   │
│  2. Bedah Saraf   → Trauma kepala & tulang belakang │
│  3. Bedah Digestif → Abdomen akut, operasi GIT      │
│  4. Bedah Urologi → Saluran kemih, batu, BPH        │
│  5. IGD 2         → Emergency lanjutan, lebih mandiri│
│  6. Bedah Plastik → Luka, rekonstruksi, kelainan    │
│  7. Bedah Umum    → Tiroid, payudara, soft tissue   │
│  8. Bedah Ortopedi → Fraktur, muskuloskeletal       │
└─────────────────────────────────────────────────────┘
```

> [!tip] Kenapa Urutan Ini Penting?
> - **IGD 1 sebelum semua stase spesialis** → kamu belajar primary survey dulu baru masuk ke detail penyakit
> - **IGD 2 di tengah** → kamu sudah punya dasar 3 stase, jadi lebih mandiri di IGD sesi kedua
> - Materi IGD 1 & IGD 2 saling overlap — banyak yang didalami di stase spesialis sebelum IGD 2

## 📐 STANDAR FORMAT SELURUH MATERI

> [!abstract] Template Wajib — Konsisten di Semua Sub-Stase

Setiap **file .md sub-topik individual** wajib memiliki 7 bagian ini secara berurutan:

### Struktur Wajib Tiap File

```
1. 🏥 Opening Kasus
   → Naratif 2-3 paragraf, setting IGD/Poli RSUD Karsa Husada Batu
   → Diakhiri: "Nah, kamu mau ngapain sekarang?"

2. 🔪 Kenapa Ini Penting?
   → BUKAN definisi — tapi konteks klinis, siapa pasiennya,
     apa yang FATAL kalau miss

3. 📚 Dasar yang Harus Kamu Tahu
   → Anatomi relevan (selalu dengan petunjuk gambar 📸)
   → Patofisiologi: ANALOGI DULU, istilah medis belakangan
   → Perjalanan penyakit sampai komplikasi

4. 🔍 Cara Kamu Mikir di Depan Pasien
   → Alur berpikir: Anamnesis → PF → Red Flags → DD → Penunjang
   → Boleh pakai diagram/tabel/flowchart

5. 💊 Tatalaksana
   → Resusitasi/stabilisasi awal → Non-operatif → Kapan konsul
   → Indikasi operasi → Monitoring → Komplikasi

6. ⚠️ Yang Sering Ditanya Konsulen
   → Format: ❓ Pertanyaan → ✅ Jawaban
   → 5-10 poin, yang paling sering jebak koas

7. ✅ Checklist Sebelum Konsul / Visite
   → Task list: "Sudah tahu ___? Sudah bisa jelaskan ___?"
```

### YAML Frontmatter Wajib

```yaml
---
title: "[Kode] — Judul Sub-Topik"
description: "Deskripsi singkat 1 kalimat"
date: YYYY-MM-DD
tags:
  - koas/bedah-[nama-stase]
  - bedah-[stase]/[kategori]
aliases:
  - alias mudah dicari
---
```

### Callout Types yang Dipakai

| Callout | Dipakai Untuk |
|---------|---------------|
| `[!danger]` | Kondisi fatal, kontraindikasi, hal yang bisa membunuh pasien |
| `[!warning]` | Tanda bahaya, jangan dilewatkan, hati-hati |
| `[!tip]` | Cara berpikir, mnemonic, shortcut klinis |
| `[!info]` | Informasi konteks, anatomi, latar belakang |
| `[!success]` | Tatalaksana yang benar, checklist yang harus dilakukan |
| `[!question]` | Pertanyaan konsulen, format ❓ → ✅ |
| `[!abstract]` | Ringkasan, konsep inti, gambaran besar |
| `[!example]` | Opening kasus, contoh konkret |
| `[!note]` | Catatan tambahan, variasi, hal yang perlu diingat |
| `[!todo]` | Checklist, progress tracker |
